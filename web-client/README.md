# WebRTC Video Chat Client

この Web クライアントは、WebSocket シグナリングサーバーを使用してビデオチャットとテキストチャットを提供します。

## 機能

### 🎥 ビデオチャット

- **WebRTC**を使用したリアルタイム音声・映像通話
- カメラ・マイクのオン/オフ切り替え
- P2P 接続による高品質な通話
- 発信・着信・通話終了機能

### 💬 テキストチャット

- リアルタイムメッセージング
- 直接メッセージとブロードキャストメッセージ
- メッセージ履歴表示
- システム通知

### 🔧 その他の機能

- 接続状態・通話状態の表示
- レスポンシブデザイン（スマートフォン対応）
- 通知システム
- ユーザーフレンドリーな UI/UX

## セットアップ

### 1. シグナリングサーバーを起動

```bash
# プロジェクトルートディレクトリで
cargo run
```

サーバーはデフォルトで `ws://127.0.0.1:8080` で起動します。

### 2. Web クライアントサーバーを起動

```bash
# web-clientディレクトリで
cd web-client
python server.py
```

または、Python 3 の場合：

```bash
python3 server.py
```

Web サーバーは `http://localhost:8000` で起動します。

### 3. ブラウザでアクセス

1. ブラウザで `http://localhost:8000` を開く
2. カメラとマイクへのアクセスを許可
3. ユーザー名を入力して「接続」をクリック

## 使用方法

### 接続

1. **サーバー URL**: WebSocket サーバーの URL（デフォルト: `ws://127.0.0.1:8080`）
2. **ユーザー名**: 一意のユーザー名を入力
3. **接続ボタン**: クリックしてサーバーに接続

### ビデオ通話

1. **通話相手**: 通話したい相手のユーザー名を入力
2. **発信**: 📞 発信ボタンをクリック
3. **応答/拒否**: 着信時は応答または拒否を選択
4. **終了**: 📞 終了ボタンで通話を終了

### メディアコントロール

- **📹**: カメラのオン/オフ切り替え
- **🎤**: マイクのオン/オフ切り替え

### チャット

1. **メッセージ入力**: 下部のテキストボックスにメッセージを入力
2. **送信**: 特定の相手がいる場合は直接メッセージ
3. **全体送信**: 全員にブロードキャストメッセージを送信
4. **Enter キー**: メッセージ送信のショートカット

## ネットワーク要件

### HTTPS 要件

本番環境では、WebRTC の制限により HTTPS 接続が必要です：

- 開発環境: `localhost` では HTTP でも動作
- 本番環境: HTTPS 必須

### ファイアウォール設定

WebRTC 通信のため、以下のポートを開放してください：

- **UDP**: 3478（STUN）
- **UDP**: 49152-65535（RTP）
- **TCP**: WebSocket サーバーポート（デフォルト: 8080）

## トラブルシューティング

### カメラ・マイクにアクセスできない

1. ブラウザの設定でカメラ・マイクの許可を確認
2. 他のアプリケーションがデバイスを使用していないか確認
3. HTTPS で接続しているか確認（本番環境）

### 接続できない

1. WebSocket サーバーが起動しているか確認
2. サーバー URL が正しいか確認
3. ファイアウォールの設定を確認

### 通話が接続されない

1. 両者が WebRTC をサポートするブラウザを使用しているか確認
2. NAT/ファイアウォールの設定を確認
3. STUN サーバーの動作を確認

### 音声・映像が届かない

1. カメラ・マイクが有効になっているか確認
2. デバイスの音量設定を確認
3. ブラウザのコンソールでエラーメッセージを確認

## セキュリティ

### 本番環境での考慮事項

1. **HTTPS 必須**: WebRTC には HTTPS 接続が必要
2. **認証**: ユーザー認証システムの実装を推奨
3. **TURN サーバー**: NAT 越えのための TURN サーバー設定
4. **レート制限**: メッセージスパム防止
5. **入力検証**: XSS 攻撃防止
